## 📖 About

**Modern Web** is a front-end web application built with the latest React and Vite tooling. It focuses on a clean interface, fast load times and a smooth developer experience, using Tailwind CSS v4 for styling, Lucide and React Icons for iconography, and syntax highlighting for presenting code.

🔗 **Live site:** [modern-web-gamma-flame.vercel.app](https://modern-web-gamma-flame.vercel.app)

## ✨ Features

- ⚡ **Blazing-fast development** with Vite and Hot Module Replacement (HMR)
- 🎨 **Modern styling** using Tailwind CSS v4
- 📱 **Fully responsive** layout for mobile, tablet and desktop
- 🧩 **Component-based architecture** powered by React 19
- 💻 **Syntax-highlighted code blocks** via `react-syntax-highlighter`
- 🎯 **Rich iconography** with Lucide React and React Icons
- 🔍 **Clean, consistent code** enforced with ESLint and React Hooks rules
- 🚀 **Continuous deployment** on Vercel

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v20.19 or newer (LTS recommended)
- npm (included with Node.js)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/khawllach/modern-web.git
   cd modern-web
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start the development server**

   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal (usually <http://localhost:5173>).

## 📜 Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server with HMR |
| `npm run build` | Creates an optimized production build in `dist/` |
| `npm run preview` | Serves the production build locally for testing |
| `npm run lint` | Runs ESLint across the project |

## 🌐 Deployment

This project is deployed on **Vercel**. To deploy your own copy:

1. Push the repository to GitHub.
2. Import it in [Vercel](https://vercel.com/new).
3. Use the default Vite settings: build command `npm run build`, output directory `dist`.

You can also deploy the generated `dist/` folder to Netlify, Cloudflare Pages or GitHub Pages.
